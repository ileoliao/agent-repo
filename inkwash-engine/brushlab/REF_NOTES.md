# 参考笔迹观察 (brushlab/ref/)

看图方式：原图裁切 + 2–3 倍放大 (huang_tingjian 330..560×520..760；zhuda_bamboo 叶/竿/淡叶三处；mifu 右上)。

## 边缘 (edge)
- 浓墨实笔 (米芾、八大竹叶)：边缘**平滑但不规则**——轮廓是缓慢起伏的曲线，在 1–2 px 尺度上有很细的纤维毛边，
  而不是逐像素的锯齿/炭笔碎渣。整条边的粗糙度很均匀地"小"。
- 湿笔外有一圈 1–3 px 的**软晕**(墨沿纤维渗出、比芯淡很多)，只在湿处有；干笔处边是硬的、断续的。
- 侧锋阔笔(八大竹叶)：两条长边基本是直/缓弧，起笔处常是方折切角，转角有小的"毛刺"；边比芯略深一点点。

## 墨色 (tone)
- 笔内墨色**平整均匀**：浓墨几乎是一块实色；淡墨 (八大淡竹叶、竹竿) 是平滑的灰，只有极低频的深浅变化
  (几十 px 量级的云状浓淡)，**几乎没有颗粒/海绵斑点**。
- 淡墨块边缘有一条稍深的**水线**(tide line) ——宽 2–4 px，比内部深 10–25%，在笔触末端/积水处最明显。
- 浓淡沿笔向缓慢变化：起笔处最浓最饱和，往后逐渐变淡/变干；笔肚压得重的一侧更深。
- 叠笔处 (两片竹叶交叠) 叠加明显更深，边界清楚。

## 枯笔/飞白 (dry brush)
- 黄庭坚细笔：飞白是**一束平行的细线** (每根 1–2 px，与笔向一致)，线之间露纸。线是长而连续的，
  偶尔断开，不是点状/虚线状。
- 八大竹竿：飞白出现在笔触**后半段、并且偏向一侧**(笔肚墨尽的一侧)，表现为长的平行擦痕，
  另一侧仍是连续墨边。前半段完全实。
- 擦痕内部在丝与丝之间常有极淡的灰 (纸面低处沾到一点墨)。

## 起笔/收笔
- 藏锋起笔：圆钝、略鼓的头，比笔身稍深 (积墨)；没有飞散的毛。
- 回锋收笔：钝圆、略宽的尾；露锋/出锋：一侧先收，最后是 1–2 根细丝的尖。
- 点 (米芾"文"上点、八大竹节点)：一次按—提——**瓜子/水滴形**，一端圆而重、一端略尖，墨最浓处在圆端中心，
  轮廓光滑；湿时外缘有极少量晕。

## 对模型的直接要求
1. 去掉所有以噪声直接啃边/抖边的做法；边的不规则只来自 (a) 笔宽的低频变化 (b) 纤维尺度 1 px 的渗化。
2. 墨色要平滑：颗粒振幅大幅降低，低频浓淡 + 水线 + 起笔饱和 + 沿笔向衰减。
3. 飞白 = 笔毛方向的长条，由笔毛墨量 (连续变化) 决定，纸面高低只决定断续，不产生点状噪。
4. 点 = 一个压力脉冲：圆端在后，尖在前（或反之），不随机甩毛。

## 破墨 / 积墨 (zhuda_lotus.jpg 叶 520..1100×600..1150、700..1100×1150..1500；zhuda_bamboo.jpg 1500..1998×900..1400)

- **湿破湿 (荷叶)**：一片叶由许多互相压着的湿墨块组成。浓淡块之间的过渡是**软的** —— 5–15 px 的羽状渐变，
  不是一条线；只有湿墨碰到干纸的外轮廓才是破碎、带飞溅的毛边。
- **淡破浓 / 水花**：浓墨块里有许多浅色"水洼"，边缘不规则 (菜花状)，洼的外沿有一圈比周围更深的边；
  洼内部是平的浅灰，不是白。八大竹叶上还有一些**圆形小水渍**：直径 10–20 px，外圈深、里面浅 (滴水的 backrun)。
- **浓破淡**：荷梗是趁叶子湿时画的浓线，线本身基本保持，但两侧有 1–3 px 的晕开，局部向湿处渗出短羽丝。
- **积墨 (竹叶相叠)**：叠压处明显更深，**每一层的边都还看得出** (深色轮廓线)，后一层不会把前一层的边抹平；
  干后再叠的边比湿时叠的边利得多。
- 对模型的要求：湿处之间的交界要软 (浓淡渐变)，湿区碰干纸处才破碎；水花要有深边浅心；
  干后叠压要保留每层边线；浓线落湿处只晕开一点、不糊成一片。
