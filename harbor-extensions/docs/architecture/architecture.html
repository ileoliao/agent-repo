Harbor Extensions · engineering view

System architecture

Every call from an extension or an agent goes through one gateway route, /gw/{connector}/{path}, is checked in seven steps, and is forwarded unchanged with the caller's identity attached. Configuration comes from Git and hot-reloads. The platform stores no business data.

Component map

Untrusted code Gateway pipeline Team-built service Request path Code or config load

The browser request leaves the bridge as fetch("/gw/…") with the session cookie and X-Harbor-Extension; cookie requests without that header are rejected, which also blocks CSRF.

A write request, end to end

Outage Console declares recovery on outage 42. The gateway decides whether the endpoint may be called; the outage service decides whether this person may do it.

Headers at the gateway

DirectionWhat happens
Caller → gatewayharbor_session cookie or Authorization: Bearer; browser also sends X-Harbor-Extension
Gateway → upstreamAllowlist only: accept, accept-language, content-type, if-match, if-none-match. Adds Authorization (service account), X-Harbor-Identity, X-Request-Id. Caller cookie and auth never pass.
Upstream → callerStatus and body unchanged; headers allowlisted (content-type, etag, last-modified, cache-control, x-total-count), plus X-Harbor-Capability
Gateway denial4xx with X-Harbor-Gateway-Error: <code> and a JSON reason and need, so the SDK can tell it from an upstream error

X-Harbor-Identity claims

HS256 in the prototype; asymmetric keys and JWKS in production. Downstream services must check signature, aud and exp, and accept traffic only from the gateway.

Before production

  • Portal login through the PAT service's Kerberos entry point; turn off dev login; HTTPS and secure cookies.
  • Identity token: asymmetric signing plus JWKS, agreed with every system owner before its connector goes live.
  • Credentials from the secrets service; rate limiter and introspect cache in shared storage (such as Redis) for multiple instances.
  • Audit as OTel spans; response body size limit or streaming; CI wiring for validate.py exit codes.
